# Research notes

Each file here is a dated research record. It is kept as written on its date.
A later note or a config change can supersede it. Read the date before you act on a finding.

- "Live" in a note means the author's own deployment at the time of the note.
  It does not describe what this repository ships.
- A note can cite scripts, data artifacts, specs, plans or a tracker that are not
  published in this repository. Treat those citations as provenance, not as files to find.
- Numbers in a note come from the corpus that the note names, on that date.
- The current shipped behavior is in `python/config.yaml` and the root `CLAUDE.md`.

Good starting points:

- `2026-05-30-weather-edge-search-dossier.md` — what the weather-strategy search ruled out, and why.
- `2026-07-19-new-data-edge-audit.md` — why `intraday_asos_high` is parked.
- `2026-10-01-favorite-bias-oos-g0-results.md` — the out-of-sample test of `favorite_bias`.
