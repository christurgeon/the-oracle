# CLAUDE.md — `python/`

Scoped to the Python runtime package. The root `CLAUDE.md` holds the project
overview, commands, data flow, key patterns (design rationale, gotchas and
incident history), configuration, and deployment notes — read it as well.

All Python source lives under `python/`. The package is imported as `python.*`
(e.g., `from python.strategies.base import Strategy`).

## Module Map

Many rows carry non-derivable operational constraints (fail-open / never-raises
contracts, incident references, "must stay an explicit 0.0 key"). Those are load-
bearing — do not treat them as prose.

| Module | Responsibility |
|--------|---------------|
| `python/common.py` | Shared enums — `Side`, `OrderStatus`, `ExecutionMode` |
| `python/settings.py` | Pydantic Settings — loads from `python/config.yaml` + `.env` |
| `python/orchestrator.py` | Main async event loop — ties all subsystems together |
| `python/data/kalshi_client.py` | Async Kalshi REST + WebSocket client with RSA-PSS auth |
| `python/data/kalshi_schemas.py` | Pydantic models for Kalshi API responses — market, portfolio, order, trade, settlement data types |
| `python/data/weather.py` | Open-Meteo ensemble forecast fetcher — GFS (30 members) + ECMWF (50 members), 50/50 default blend (20 cities collected / 9 traded, NWS-aligned coords, `fraction_between` for bracket markets, supports `temperature_2m_max` and `temperature_2m_min`) |
| `python/data/bias_correction.py` | GFS ensemble bias correction — loads a bias table (path via `weather.bias_table_path`; `null`=canonical ERA5-fit `data/gfs_bias/bias_correction.json`), applies location-shift to ensemble members before bracket fraction computation (SNR gate, shrinkage, cap). Enabled in the shipped config (30% shrinkage, ±5°F cap). **Settlement-anchored (NWS-CLI) table** `data/nws_bias/bias_correction.json` (built by `scripts/build_nws_bias_corpus.py`+`fit_nws_bias.py`, OOS-validated by `validate_nws_bias.py`: held-out GFS MAE 3.30→3.00°F) re-anchors the correction from ERA5 reanalysis to the NWS settlement source; EMOS-owned cells omitted. **The shipped config sets `bias_table_path: data/nws_bias/bias_correction.json`** (re-validated 2026-06-05, MAE 3.30→3.00°F, 7 cells promote, only non-trading DEN/high regresses); `null` rolls back to the ERA5 table bit-identically. |
| `python/data/calibration.py` | Single source of truth for weather calibrators — `IdentityCalibrator`, `IsotonicCalibrator`, `PlattCalibrator`, `PerTypePlattCalibrator`; `load_calibrator(config, key=)` resolves live vs shadow. Keys are canonical strike labels (`greater`/`less`/`between`). No sklearn at runtime. Per-cell live calibrator selection (isotonic vs EMOS) is wired in `weather_evaluation.py:evaluate_market_pure` via the `weather.emos_enabled_cells` config list (currently **empty — all-isotonic** since 2026-06-05; LAX/low suspended). |
| `python/data/emos.py` | Hermetic EMOS coefficient loader — `EmosTable` (atomic build-then-swap, smoke-test, hot-reload), `emos_probability` pure math (Gaussian-EMOS for between/greater/less). Imports limited to stdlib + numpy + scipy. |
| `python/data/asos_posterior.py` | Hermetic ASOS intraday posterior math (stdlib+scipy+`Direction` only) — `prob_daily_max_at_least` (left-truncated Student-t remaining-gain survival) + `bracket_probability` over the NWS-rounding window. Used by `intraday_asos_high`. |
| `python/data/asos.py` | Runtime IEM/ASOS hourly-obs client — `AsosClient.max_so_far` (**fail-open**: returns None on any error; station map asserted vs `CITY_TO_CLI_LOCATION`, CHI=MDW) + `ClimatologyTable.load/lookup` (remaining-gain climatology `(city,month,hour_utc)→(μ,σ,n,source)`, `(city,hour)` pool fallback). Artifact: `data/asos/climatology.json` (built by `scripts/build_asos_climatology.py`). |
| `python/data/fb_climatology.py` | Hermetic strike-climatology for favorite_bias (stdlib+scipy only) — `strike_z`/`clim_yes_prob` pure math + `FbClimatologyTable.load/lookup` (**never-raises**, disabled-on-error like `EmosTable`; `(city,var,month)→ClimEntry(μ,σ,n,source)` with `(city,var)_pool` fallback). Scores a strike's climatological rarity/base-rate at signal time. Artifact: `data/calibration/fb_climatology.json` (built by `scripts/build_fb_climatology.py`). Instrumentation-only + a default-off tail guard. |
| `python/analytics/audit_tripwires.py` | Freshness / rotation / artifact-age tripwires that emit `DriftAlert`s for the calibration monitor, each carrying an `owner` (suppressed if that strategy isn't `configured_to_trade`, fail-open) and an `ack_key` (non-null only when a human `/ack` can meaningfully silence it — see `docs/calibration-runbook.md` §6). |
| `python/data/nws.py` | NWS Daily Climate Report (CLI) fetcher — parses official high/low temps from the exact source Kalshi uses for settlement (20 cities collected, `CITY_TO_CLI_LOCATION` mapping) |
| `python/data/contract_watcher.py` | WebSocket market monitor — tracks live market updates, orderbook changes, execution fills for real-time signal feedback |
| `python/data/kxrain_markets.py` | KXRAIN ticker + geography primitives — `parse_kxrain_ticker` (28-city map, date-bounded legacy aliases PROV→PVD/MIL→MKE/COL→CLL; `KXRAIN_PREREGISTERED_CITIES` is the frozen 27-city gate universe — PIT, launched 2026-09-23, is logged but never gated), `KxRainMarketKey.corpus_key` = `(station, settlement_date)` (**the canonical identity — Kalshi renames the ticker suffix mid-corpus**), `lst_day`/`in_entry_window` on FIXED-offset LST (never `ZoneInfo`, deliberately), `station_from_rules`/`station_mismatch`. No import-time `assert`. |
| `python/data/kxrain_trades.py` | `/markets/trades` window aggregation — `summarise_trade_window` over a 30-minute lookback, `MAX_PRINTS` cap, fractional `*_fp` sizes kept as floats (`int(float(...))` dropped 24 of 100 captured prints). |
| `python/data/kxrain_decision.py` | The pre-registered buy-NO decision rule — `evaluate_decision` with a frozen skip-reason precedence and a signature firewall (it cannot see the gauge stream). `eligible: null` on a failed trades fetch, never coerced to false. |
| `python/data/kxrain_rows.py` | Pure row builders for all five JSONL streams + `encode_row`'s PIPE_BUF guard (the writer has none and discards `os.write`'s return) and `quantise_price`. Closed `CAPTURE_OUTCOMES` / `TICK_OUTCOMES` vocabularies. No builder raises. |
| `python/data/kxrain_budget.py` | Per-tick request ledger — `reserve_market_pair` (both legs or neither, so a cap binding mid-pair cannot produce a row whose halves describe different instants) and a bounded `reserve_book_overdraft` for the one artifact that cannot be reconstructed. |
| `python/data/kxrain_ledger.py` | Durable virtual-entry ledger keyed on `corpus_key` + the shared `atomic_write_json`. A durable artifact, not a JSONL replay: `ForecastsRawWriter` seeds its rotation boundary in LOCAL time and its `os.replace` has no existence check. Synchronous by contract — the async caller offloads. |
| `python/data/kxrain_observer.py` | The observer coroutine — logging only, **zero orders structurally**, no import path to `python.execution`/`risk`/`strategies` (an AST test enforces it). Owns its own single-worker executor rather than the shared default pool, a per-tick disk self-limit, and a liveness detector keyed on rows that **reached disk**. Launched by the orchestrator only when `kxrain_shadow.enabled` (ships `false`); never registered as a `Strategy`, and a `risk.strategy_allocations` key for it crashes startup. Tick rows record `tick_interval_seconds`. |
| `python/data/kxrain_settlements.py` | KXRAIN settlement sweep + durable `SettledIndex` — the corpus's only disaster-recovery path. Bounded to 8 pages of the newest-first settled listing (~28 days of reach); idempotent on `(station, settlement_date)`, never on the date alone; **refuses to write unless `result` is `"yes"`/`"no"`** (an open market carries `result: ""`, which would be a fabricated NO win in a buy-NO corpus). Never raises; a partial fetch keeps the pages it got. Deep walk: `scripts/kxrain_backfill_settlements.py`. |
| `python/strategies/base.py` | Abstract `Strategy` class + `TradeSignal` frozen dataclass |
| `python/strategies/weather_edge.py` | Weather edge strategy — per-city series scan (KXHIGH + KXLOWT), API-field market parsing (strike_type/floor/cap), dollar-denominated prices, greater/less/between support, orderbook depth check with VWAP fill pricing, per-cell calibrator dispatch (isotonic + EMOS for promoted cells), city/var exclusion filter, per-day event cap |
| `python/strategies/per_day_event_cap.py` | Per-day event cap — `PerDayEventCap` class + `hydrate_per_day_state_from_trades_jsonl` helper + ticker-parser fallback. Caps weather signals to at most `max_bets_per_day_per_event` per `(city, var, forecast_date)` per UTC day, persisting across scans. |
| `python/strategies/same_day_gate.py` | Same-day trading gate — blocks weather markets from trading the same day the observation occurs (high/low settle at next day). Late-day override gate parked for future research |
| `python/strategies/favorite_bias.py` | Favorite-bias strategy (model-free) — buys YES on greater/less favorites (market mid in `band_low`–`band_high`) at lead-1 using a pre-fitted isotonic g(mid) map; taker execution; defers to weather_edge on shared events; ships `enabled: false` (out-of-sample validation did not confirm a forward edge). Has its own `excluded_city_vars`. Logs strike-climatology features (`z_strike`/`q_clim` via `python/data/fb_climatology.py`) on every audit row + a **default-off** tail-strike guard (`max_strike_climatology_z`). |
| `python/strategies/intraday_emos_high.py` | Intraday EMOS HIGH strategy — trades same-day KXHIGH markets (MIA/high, LAX/high) by shifting the EMOS posterior to a later snapshot; reuses `weather_evaluation.evaluate_market_pure`. **⚠ PARKED 2026-06-07 (`enabled: false`)** — was shadow-only 2026-05-29→2026-06-07; parked because its forward corpus stalled + was edge-selected and it's redundant with the better-positioned `intraday_asos_high`. Code intact (un-park = `enabled: true`). |
| `python/strategies/intraday_asos_high.py` | Intraday ASOS nowcast strategy + standalone `asos_evaluate`/`size_candidate` — trades same-day KXHIGH (MIA/AUS/CHI/NYC high; LAX informational) from a real-time ASOS-observation posterior (`asos_posterior.bracket_probability`) behind physical guards (boundary-distance, σ-floor, ASOS-freshness, bad-prelim-informational), NO learned calibrator. Does NOT use `evaluate_market_pure` (no GFS ensemble) — reuses sizing/fees/`_select_one_per_event`/depth-check. **PARKED (`enabled: false`)** — see the root `CLAUDE.md`. Hermetic from `weather_edge`. |
| `python/analytics/boundary_distance.py` | Pure `boundary_distance(mean, floor, cap, strike_type)` for the boundary-distance suppressive filter (Path 7a) — drops between-grazers whose blended mean sits within a per-cell °F threshold of an NWS-rounding boundary. Enabled in the shipped config for **MIA/low @ 0.5°F** (since 2026-05-29) via `weather.boundary_filter_cells` |
| `python/analytics/sizing.py` | Fractional Kelly criterion for YES/NO binary contracts |
| `python/analytics/fees.py` | Kalshi fee calculations — `fee_per_contract()` (conservative, per-contract ceil) and `order_fee()` (total-order ceil to the cent; overstates current $0.0001 billing by < 1¢). Taker, index-taker, and series-aware maker multipliers: a maker fill is free when `ticker` is in `MAKER_FEE_FREE_SERIES` (verified `fee_type: quadratic`), else 0.0175 |
| `python/analytics/backtest.py` | Backtest engine — replays historical weather markets against stored forecasts, reuses production functions |
| `python/analytics/bracket_metrics.py` | Bracket market evaluation — groups markets by event, computes bid excess, arbitrage metrics, and boost factors for bracket-complete events |
| `python/analytics/audit_log.py` | Owns the three JSONL diagnostic audit streams (`eval_audit`/`candidate_audit`/`scan_funnel`) — `RejectionReason`, `ScanFunnel`, `AuditLogger` (synchronous, durable the instant `append` returns; used by backtest/scripts/tests), `BufferedAuditLogger` (parks rows, drains via `asyncio.to_thread` on `flush_sinks`; used by live async strategies). `weather_edge` builds its sinks with `buffered=True` and flushes at the end of `scan()`, after the Stage-1 loop, at the end of `generate_signals()`, and in `aclose()` — `generate_signals()`'s Stage-1 loop runs ~300 synchronous `evaluate_market_pure` calls with no `await`, so inline audit writes previously stalled WebSocket reads. |
| `python/analytics/attribution.py` | P&L attribution framework — maps settled trades to original signals, computes per-city/per-side/per-model breakdown for daily reports |
| `python/analytics/strategy_attribution.py` | Reporting-side strategy resolver — `build_strategy_index(rows)` maps `order_id → strategy` from the trade log, preferring top-level `strategy` over `metadata.strategy` (reconciler synthetics, often "unknown" after restart). `resolve_strategy_by_order_id` enriches settlement rows in `fetch_shadow_settlements.py` so `shadow_settlements.full.json` carries reliable strategy for all consumers. |
| `python/analytics/calibration_monitor.py` | Calibration health monitoring — tracks prediction vs outcome divergence, emits `CalibrationAlert`s via audit tripwires. Feeds `daily_trade_report.py` calibration_ratio and SPLIT MODEL detection |
| `python/analytics/outcomes.py` | Outcome event dataclass — wraps settled market results with date/city/var/temperature for calibration analysis |
| `python/analytics/prediction_log.py` | Prediction audit stream — logs raw model outputs (`predictions.jsonl`) and post-filter evaluations (`eval_audit.jsonl`) before trading cap, preserving unconstrained model behavior for calibration |
| `python/analytics/emos_fit.py` | Pure functions for offline Gaussian EMOS fitting — `crps_gaussian`, `fit_cell` (L-BFGS-B with bounds `b ∈ [0.3, 1.5]`, `c ≥ 1e-6`, `d ≥ 0`), `cv_fold_iter` (5-fold expanding-window time-series CV), `bootstrap_cell` (B=400 + `unstable_b`/`unstable_d` warnings), `synthetic_bracket_brier`, `skip_rule`, `fit_one_cell`. No I/O. Hermetic — must not import from production runtime. |
| `python/risk/manager.py` | Risk controller — exposure limits, daily loss halt, drawdown, circuit breakers, kill switch |
| `python/risk/persistence.py` | Risk state persistence — atomic JSON writes (via `python/utils/atomic_write.py`), schema versioning, day-boundary reset detection, heartbeat file |
| `python/execution/engine.py` | Order execution — shadow (log-only), paper (sandbox), live modes |
| `python/execution/shadow_broker.py` | Shadow trading mock broker — simulates fills at best-bid/ask, position tracking, and P&L computation for backtesting |
| `python/execution/trade_log.py` | `TradeLogEvent` enum + `is_pnl_relevant_row` / `is_known_event` row-filter helpers. Single schema-evolution gate for every consumer of `state/trades.jsonl`. |
| `python/execution/fills_reconciler.py` | Periodic write-behind reconciler that backfills synthetic fill rows from `/portfolio/fills` for any Kalshi-confirmed fill missing from `state/trades.jsonl`. Owner-toggleable via `/disable_reconciler`; structured `reconciler_tick` logs. Includes a `seen_cursors` cycle-defense on `_fetch_fills_paginated` (added after the trade-log writer 20× inflation incident); cycle aborts set `ReconcileTick.cycle_aborted_at_cursor=True` and escalate to CRITICAL Telegram alert. Emits a per-tick batched INFO Telegram alert (`[reconciled]` label) listing the `BUY_ENTRY` synthetic rows it back-fills, so restart-orphan / never-tracked fills are per-fill visible (side/ticker/size/price/strategy), not just an aggregate count (formatter wrapped locally so it can't disturb the never-raises tick). |
| `python/dashboard/tui.py` | Textual TUI dashboard — portfolio, trade log, signals, risk status |
| `python/notifications/base.py` | `AlertLevel` enum + `Notifier` protocol — abstract interface for notification backends |
| `python/notifications/telegram_bot.py` | `TelegramNotifier` — Telegram bot with owner-only auth, command handlers, push alerts, rate limiting. Runs as background asyncio task using long polling (no inbound ports) |
| `python/notifications/formatters.py` | Plain-text message formatters for all Telegram commands and push alerts |
| `python/utils/log_config.py` | Structured logging setup via structlog — JSON/console renderers, file rotation, per-strategy contextvars binding |
| `python/utils/atomic_write.py` | `atomic_write_text` — temp file + `os.replace` in the target dir; cleans up and re-raises on failure. `fsync=True` adds file + parent-dir fsync (dir fsync best-effort). Shared by risk persistence, the fills reconciler, calibration monitor and tripwire state files, the calibrator harness, and operator scripts. |
| `python/utils/retry.py` | Shared async retry utility — exponential backoff, `Retry-After` header support, `RetryExhaustedError`. Used by weather.py and nws.py |
| `python/utils/jsonl.py` | JSONL reader/writer utilities — appending/reading record streams from `state/trades.jsonl` and audit logs |
| `python/utils/jsonl.py` (`ForecastsRawWriter`) | Append-only JSONL writer for `state/forecasts_raw.jsonl` — daily UTC rotation, retention pruning (`audit_log_retention_days`), per-record atomic `os.write` append (PIPE_BUF guarantee). |
| `python/utils/ticker_dates.py` | Kalshi ticker date parsing — extracts forecast date, resolution hour from market tickers (e.g., `KXHIGH-26MAY15H1600`) |
| `scripts/*` | Analysis, calibration, and operations tooling — full per-script behavior in **`docs/scripts-reference.md`**; runnable commands in the Commands section above. |
